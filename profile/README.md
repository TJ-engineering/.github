# TJ Engineering

**Ideas into working projects.**

TJ Engineering brings together open-source software at the intersection of engineering and academic scholarship. The current portfolio focuses on textual corpus research, biblical studies, and the digital humanities, with tools for working with Ancient Greek and Biblical Hebrew.

## Explore the projects

* [Perseus MCP](https://github.com/tonyjurg/Perseus-mcp) connects research tools to the Perseus Digital Library for Greek and Latin text discovery and retrieval.
* [Morphkit](https://github.com/tonyjurg/morphkit) supports Ancient Greek morphological analysis and tag comparison.
* [Doc4TF](https://github.com/tonyjurg/Doc4TF) generates linked documentation for Text-Fabric datasets.
* [N1904addons](https://github.com/tonyjurg/N1904addons) and [BHSaddons](https://github.com/tonyjurg/BHSaddons) add features to Greek New Testament and Biblical Hebrew datasets.

Visit the [project portfolio](https://tj-engineering.github.io/) for the full collection, documentation, and publication links. Several project repositories are hosted under [@tonyjurg](https://github.com/tonyjurg).
